If you voluntarily choose to sign in via Google Sign-In / Firebase Authentication (for cloud synchronization of your favorite feeds and settings across devices), we collect:

  • Your email address
  • Your public display name
  • A unique system-generated Firebase User ID (UID)

To ensure app reliability, analyze anonymous performance, and serve advertisements, certain non-sensitive device data is automatically processed:

  • Device Identifiers: Advertising ID (GAID), Firebase App Installation ID.
  • Technical Information: Device model, manufacturer, operating system version, and system language.
  • Diagnostics & Performance: App crash logs, system stack traces, and session duration.
  • Subscription Status: Anonymous transaction tokens processed via RevenueCat to verify active premium access.
